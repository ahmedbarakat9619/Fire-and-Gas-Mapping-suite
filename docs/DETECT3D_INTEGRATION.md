# التكامل مع Detect3D

## ما المعروف عن Detect3D (مصادر عامة)

- برنامج Windows من Insight Numerics لتحليل Fire & Gas Mapping ثلاثي الأبعاد.
- يعمل على ملفات CAD الخاصة بالمشروع، وبه أداة لإنشاء نموذج 3D من رسومات ممسوحة أو ملفات DWG ثنائية الأبعاد.
- **يستورد مواقع الكواشف من Excel**، و**يصدّر مواقع الكواشف إلى Excel وإلى CAD (DWG/DGN)**.
- **جداول نتائج التغطية تُصدّر إلى Excel**، بالإضافة إلى contours و isovolumes.
- Gas mapping بأحجام سحب متعددة (Volumetric)، و Scenario mapping بمشاركة بيانات مع برنامج CFD الخاص بهم (in:Flux).
- تحسين تلقائي لتوزيع الكواشف بالخوارزمية الجينية (Genetic Algorithm).

> لم يتم الوصول لدليل المستخدم الرسمي، لذلك لم يُفترض أي قالب أعمدة ثابت. كل تبادل يمر عبر **خريطة أعمدة + تحويل إحداثيات** قابلين للتعديل ويُحفظان داخل ملف المشروع `.fgs`.

## الدورة

```
Suite (الخطوات 1-6) ──► ملف التسليم Excel ──► Detect3D: استيراد النموذج + المناطق + الكواشف
        ▲                                                │ تحليل 1ooN/2ooN، تحسين GA
        │                                                ▼
   مقارنة بالأهداف ◄── جدول التغطية Excel + توزيع الكواشف النهائي + صور الخرائط
        │
        └─ FAIL ← تعديل الكواشف وإعادة التحليل (ISA Figure 2: الخطوات 7-10 تكرارية)
        └─ PASS ← الفعالية (الخطوة 8) ← التقرير (الخطوة 10)
```

## ملف التسليم (Export)

| الورقة | المحتوى |
|--------|---------|
| `Detectors` | Tag, Type, Model, X, Y, Z, Azimuth, Elevation, Range, H-FOV, V-FOV, Receiver X/Y/Z (OPGD), Set point, Zone, Status |
| `Zones` | حدود المنطقة، الدرجة، الهدف، الحد الأدنى المقبول، حجم الحريق التصميمي kW، قطر السحابة، التصويت المقاس عليه |
| `Geometry` | صناديق المعدات والعوائق (Xmin..Zmax) لبناء نموذج مبدئي عند عدم توفر 3D |
| `Detect3D set-up` | 11 خطوة إعداد بالقيم المطلوبة والمرجع |
| `Coverage results (fill)` | قالب: Zone, Hazard, 0 detectors, 1 detector, 2+ detectors, 1ooN, 2ooN |

### تحويل الإحداثيات (الخطوة 7 ①)

- البرنامج يعمل بالمتر، Pan عكس عقارب الساعة من الشرق (+X)، Tilt سالب = لأسفل.
- التحويل: دوران شبكة المصنع ثم إزاحة (dx, dy, dz) ثم الوحدة (m أو mm).
- اصطلاح Azimuth: CCW من الشرق، أو بوصلة CW من الشمال (`bearing = 90° − pan`).
- اصطلاح Tilt: سالب لأسفل، أو موجب لأسفل (Declination).
- التحويل عكسي تماماً عند الاستيراد (مختبر في `tests/test_core.py::test_detect3d_roundtrip`).

## الاستيراد (Import)

1. **توزيع الكواشف**: Excel/CSV ← اختيار الورقة ← خريطة أعمدة (تخمين تلقائي) ← استبدال أو دمج بالـ Tag.
2. **نتائج التغطية**: أي جدول به اسم المنطقة + (0/1/2+) أو (1ooN/2ooN) بالنسبة المئوية أو ككسور؛ تُستنتج القيم الناقصة (مثلاً 1 كاشف = 1ooN − 2ooN).
   أسماء المناطق في الملف يجب أن تطابق أسماء المناطق في البرنامج.
3. **صور الخرائط**: تُدرج في التقرير.

## خطوات عملية مقترحة

1. أكمل الخطوات 1-5 في البرنامج.
2. الخطوة 6: توزيع مبدئي أو «تحسين تلقائي» حتى يقترب من الهدف.
3. الخطوة 7: اضبط التحويل والأعمدة ← صدّر ملف التسليم.
4. في Detect3D: اتبع ورقة `Detect3D set-up` ← حلل ← حسّن ← صدّر جدول التغطية وقائمة الكواشف وصور الخرائط.
5. الخطوة 7: استورد ← راجع جدول المقارنة. كرر حتى PASS (أو MARGINAL مقبول لدرجات A*/A).
6. الخطوات 8-10: الفعالية، المبررات، التقرير.
